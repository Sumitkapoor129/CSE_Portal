# Code Quality Review — CSE_portal

Reviewer: Code Quality Reviewer (read-only)
Date: 2026-09-16
Scope: `backend/` (Express 4 + TS + Mongoose 8) and `frontend/` (React 19 + Vite 6 + TS strict + Tailwind v4), branch `feature/debug-and-optimize`.

## Summary

The codebase is in **good overall health**. Architecture is clean and consistent: controllers–services–utils layering is respected, `asyncHandler`/`AppError` error plumbing is universal with correct 4xx/5xx usage in the majority of endpoints, route-level auth+`authorize` guards are applied on every protected router, the **F4 supervisor-ownership gate is correctly implemented** on every student-scoped supervisor route, refresh tokens are opaque (random 32-byte) values hashed at rest with rotation + replay protection, and passwords/OTPs are bcrypt-hashed (cost 10–12). The frontend shows excellent type discipline (zero `any`/`@ts-ignore`), consistent loading/empty/error rendering via `QueryError` + skeletons on all 24 data pages, code-split lazy routes, and an unusually well-tested API client (single-flight refresh, one retry). All gates pass (typecheck/build/jest/vitest; frontend lint = 1 pre-existing warning).

The problems are concentrated in: (1) **security hardening of defaults/authorization edges**, (2) **two genuinely broken features** (semester-scoped deadline notifications; general approval requests), (3) **validation/4xx-classification gaps**, and (4) **backend tooling/lint being broken**. None of the failures surface in the current test suites because tests exercise mostly happy paths and the `testApp` mounts only `auth` + `student` routers — the supervisor/admin routes and the deadline scheduler's semester branch are effectively untested.

6. **Important** — Supervisor `createEvent` can invite students not assigned to the supervisor.

Fix the above, then re-run backend typecheck/build/lint, frontend typecheck/lint/build, and the jest/vitest suites before merge. Remaining items are Minor and can land in follow-up work.
